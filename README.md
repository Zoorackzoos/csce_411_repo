# csce 411 repo

## how to run
i ran this using pycharm. if you're on vscode idk how to help you.
1. if pycharm tells you something about the interpeter go to the settings menu, type in "interp" to see if the interpreter comes up and then select one from the dropdown
2. go to src --> execute_both_files
   1. from there you can see the list where all of the files are ran. 
   2. every file is ran that is in that list and it generates a log file in "export_log_files"
      1. from there you can read the core components of what the algorithm got
   3. if you need to test your TA files, then just place it in "inported_csv_files" and hook it up to the list. and maybe remove the old file paths from the list as well so you don't have to wait as long for "yao's file" to finish logging
3. The last guy who graded a zipped repo like this told me he couldn't run it. don't be that guy please god.
